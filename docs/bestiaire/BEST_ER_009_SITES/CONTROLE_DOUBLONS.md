## Reproduction hors réseau

L’instantané contient les noms, IDs, alias, chemins et versions des corpus ; les 41 candidates historiques comportent les extraits de morphologie, habitat et capacités. Les textes publics des rapprochements les plus proches et les données descriptives008 sont également conservés. Aucun brut de campagne privé, note MJ, sauvegarde ni donnée de joueur n’y figure.

L’algorithme applique aux noms et alias : normalisation Unicode NFD, retrait des diacritiques, minuscules françaises, remplacement des caractères hors a-z0-9 par un espace, réduction des espaces, puis égalité exacte. Les IDs sont comparés sans normalisation aux IDs documentaires et aux candidats de registre ; l’unicité des slugs est contrôlée dans le lot. Rejouer ces comparaisons depuis les tableaux github.corpora et sites.corpora produit les zéros enregistrés dans [controle-doublons-v0.1.json](controle-doublons-v0.1.json). Vérifier d’abord son champ snapshot.sha256. L’analyse sémantique reste une relecture humaine, pas une preuve automatique de taxonomie.

### Exemple de vérification autonome (Node.js)

À exécuter depuis le dossier du lot, sans réseau. Le script s’appuie seulement sur les deux fichiers JSON livrés :

~~~javascript
const fs = require('node:fs');
const assert = require('node:assert/strict');
const crypto = require('node:crypto');
const raw = fs.readFileSync('snapshot-sources-v0.1.json');
const s = JSON.parse(raw);
const c = JSON.parse(fs.readFileSync('controle-doublons-v0.1.json'));
assert.equal(crypto.createHash('sha256').update(raw).digest('hex'), c.snapshot.sha256);
const normalize = value => String(value ?? '').normalize('NFD')
  .replace(/\p{Diacritic}/gu, '').toLocaleLowerCase('fr')
  .replace(/[^a-z0-9]+/g, ' ').trim();
const identities = [...s.github.corpora, ...s.sites.corpora]
  .flatMap(corpus => corpus.identities);
assert.equal(s.candidates.length, 10);
assert.equal(new Set(s.candidates.map(e => e.id)).size, 10);
assert.equal(new Set(s.candidates.map(e => normalize(e.name))).size, 10);
assert.equal(new Set(s.candidates.map(e => e.slug)).size, 10);
for (const candidate of s.candidates) {
  assert.equal(identities.some(e => [e.id, e.canonicalId, e.candidateRegistryId]
    .filter(Boolean).includes(candidate.id)), false);
  assert.equal(identities.some(e => [e.name, ...(e.aliases ?? [])]
    .some(name => normalize(name) === normalize(candidate.name))), false);
}
console.log('10 fiches : 0 collision exacte ; empreinte vérifiée.');
~~~
