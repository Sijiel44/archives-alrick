## Sources et reproduction

[lot-v0.1.json](lot-v0.1.json) est la source structurée. Le générateur fourni `render-pack.mjs` produit cet aperçu, les dix fiches Markdown et le présent index :

`node render-pack.mjs <dossier-du-lot>`

Les illustrations restent des propositions originales. Consulter briefs, textes alternatifs, provenance et empreintes dans le manifeste du lot. Générer cet aperçu ne modifie ni les illustrations, ni les registres, ni le catalogue public.

## Avant une intégration

1. Valider le statut des fiches et l’attribution éventuelle de codes permanents ; préserver réserves et rapprochements.
2. Recontrôler les doublons contre le catalogue Sites courant et adapter les champs au véritable contrat du Studio. Ce paquet n’est pas un import de production.
3. Valider les illustrations et leurs usages ; vérifier liens, médias, filtres, bureau et mobile dans la source courante du projet Sites existant.
4. Publier seulement les fiches explicitement approuvées après recette, sur le projet existant. GitHub et une pull request ne publient rien dans Sites.

Archives d’Orin, sauvegardes de campagne et secrets MJ restent hors de ce lot.
