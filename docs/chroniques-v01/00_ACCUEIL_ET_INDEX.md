# 00 🧭 Les Chroniques d’Entre-Rives — Centre de pilotage v0.1

**Statut :** proposition documentaire ORG-001, branche indépendante ; pas de fusion ni publication.  
**Dépôt :** `Sijiel44/archives-alrick`.  
**Objectif :** retrouver rapidement les référents, leurs missions, les contrats et les preuves.

## 01 🏛️ Principes du projet

Les Chroniques d’Entre-Rives v0.1 ne remplacent pas destructivement les Archives d’Alrick. Le site public historique, Quartz, les fiches Markdown, les codes documentaires, les moteurs M01–M05, le Grimoire, le Bestiaire et les sauvegardes sont préservés. Le développement v0.1 avance par branches spécialisées, avec revue avant intégration.

**Deux priorités liées :** (1) langage mécanique commun aux créations et (2) Studio MJ local avec projection joueur à liste blanche. Aucun autre module ne doit réinventer les formules 5d6. Le plafond 12 sur les caractéristiques n'est pas réintroduit ; les niveaux ordinaires actuels vont de 1 à 25.

L'Odyssée d'Orin reste une source d'idées et une chronique distincte, pas la chronologie obligatoire des campagnes. L'époque située environ 500 ans plus tard reste un projet éditorial non canonisé. Toute fiche doit pouvoir être utile à d'autres MJ et joueurs.

## 03 🔒 Règles de conservation

1. Aucune suppression de l'ancien site, de ses fiches ou de ses sauvegardes.
2. Aucun secret MJ dans GitHub public, GitHub Pages, les index publics, les logs ou la fenêtre joueur ; une page `unlisted` n'est pas privée.
3. Toute variante de campagne est une copie et référence sa fiche source ; elle n'écrit jamais dans le canon.
4. Les statuts **fait joué / lore validé / proposition / prototype / adaptation** sont indépendants des statuts techniques **testé / fusionné / publié**.
5. Aucune fusion, déploiement Pages, canonisation, migration destructive ou transaction réseau sans décision explicite de la DG et du créateur.
6. Le multijoueur synchronisé est différé ; Discord peut servir de communauté et de lieu de rendez-vous.

## 04 🧪 Règle de preuve

Un rapport de chat n'est pas une preuve GitHub. Chaque référent vérifie la branche, la PR, les commits et les CI qu'il revendique ; les vérifications en navigateur n'équivalent pas à une recette sur téléphone ou à une session humaine. Une mission sans commit est marquée **proposée/préparatoire**, non **déposée**.

## 05 🧩 Limite de l'outil ChatGPT

Les intitulés de chat `00 🧭 DG`, `10 🧮 MATH` etc. sont une convention d'organisation, pas des sous-dossiers automatiques dans l'interface ChatGPT. Ce dossier GitHub ne crée ni ne renomme les conversations ChatGPT ; les prompts doivent être ouverts dans les conversations par l'utilisateur ou via un mode Work capable de piloter l'interface.
